ARDUINO + BLUETOOTH

Voice Control Robot

A voice-controlled robotic car operated through mobile Bluetooth commands and an Arduino-based control system.

Project Overview

This project demonstrates a robotic car controlled from a mobile phone using Bluetooth communication.

Voice commands are converted into movement commands and sent to the Arduino-based robot.

Voice Commands

⬆ Forward
⬇ Reverse
⬅ Left
➡ Right
⛔ Stop

Components

✓ Arduino

✓ Bluetooth module

✓ Motor driver

✓ Sensors

✓ Wheels

Technologies

Arduino Bluetooth C/C++ Robotics
